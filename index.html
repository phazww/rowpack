One document per group of rows, with a table that grows to fit them

A sheet of jobs becomes one invoice per client. A list of orders becomes one packing slip per customer. Each document gets all of that group's rows as table rows, and a total.

Install for Google Sheets

Works inside your Google account. Your data is not sent anywhere else.

How it works

1. Pick the column

Choose what to group by: client, project, category, employee. One document per value.

2. Write the template

A normal Google Doc. Put [[Item]] in one table row, and that row repeats for every sheet row in the group.

3. Generate

Google Docs, PDFs or both, in a folder in your Drive, with a list of links back in the sheet.

Template syntax

In the templateBecomes
{{Client}}The value of the column for the group, once per document.
[[Item]] [[Qty]] in a table rowThat row, repeated for every sheet row in the group, in sheet order.
{{SUM:Amount}}The group's total of a column, written the way the column shows numbers: decimals, separators, currency sign.
{{COUNT}}, {{TODAY}}Number of rows in the group, today's date.

Values are copied as the sheet displays them, so dates and amounts keep their formats. "Check template" lists any name that matches no column before you generate.
